State (Состояние)
Трансформер. Допустим, может пребывать в след. состояниях
- выключен (спит)
- включен в режиме "робот"
- включен в режиме "автомобиль"

Может быть реализован как интерфейс State с заданными обязательными методами:
- turnOn() - включить
- turnOff() - отключить
- changeMode() - поменять состояние

Для каждого состояния реализуется свой класс, имплементирующий State и реализующий его методы. Например:
class SleepState implements State{
	turnOn(){
		включаемся
	}
	turnOff(){
		ничего не делаем
	}
	changeMode(){
		устанавливаем состояние, в котором будем просыпаться
	}
}
Кроме этого создаем класс непосредственно самомго трансформера, которому задаем поле, отвечающее за текущее состояние (переменная типа State)
